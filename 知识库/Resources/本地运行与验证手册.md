# 本地运行与验证手册

- 最后更新：2026-08-16

## 后端

```powershell
cd D:\agent-data
python -m uvicorn smart_ask_data.api:app --host 127.0.0.1 --port 8000 --reload
```

验证地址：

- 健康检查：`http://127.0.0.1:8000/health`
- OpenAPI：`http://127.0.0.1:8000/docs`

## DeepSeek 配置

复制 `config/settings.local.example.yaml` 为 `config/settings.local.yaml`，在本地文件中配置 `llm.api_key`。该文件应保持在 Git 忽略列表中。默认模型为 `deepseek-v4-flash`，接口模式为 `chat_completions`，思考模式为 `enabled`。

不要把真实密钥写入 README、知识库、测试代码或提交记录。

## 前端

```powershell
cd D:\agent-data\frontend
npm install
npm run dev
```

默认访问 `http://127.0.0.1:3000`，默认后端地址为 `http://127.0.0.1:8000`。可通过 `NEXT_PUBLIC_API_BASE_URL` 修改。

## 自动化验证

```powershell
cd D:\agent-data
python -m unittest discover -s tests -v

cd D:\agent-data\frontend
npm run build
```

## 人工验收问题

- `昨天香港开户人数是多少？`
- `最近7天每天的开户人数`
- `总的开户数是多少？然后每个地区的开户数是多少？`
- `各地区开户人数和占比分别是多少？`
- `昨天利润是多少？`（应拒绝作为可靠指标回答）

验收时除最终答案外，还应检查知识命中、规划时间与维度、SQL 白名单与过滤条件、结果评分依据、逐轮历史，以及页面是否明确标识 Demo/真实数据环境。
