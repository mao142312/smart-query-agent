# Smart Ask Data 当前成果

- 状态：Demo 已可运行，正在向完整项目演进
- 最后更新：2026-08-16
- 项目目标：让用户通过自然语言查询指标，并能看到知识检索、语义规划、SQL 校验和结果评分的完整证据链。

## 当前交付物

### 后端

- FastAPI 服务，入口为 `smart_ask_data.api:app`。
- `GET /health` 返回运行环境、知识库、查询引擎和 LLM 后端状态。
- `POST /v1/ask` 接收自然语言问题并返回答案、综合可信度、分项评分和验证报告。
- 编排流程包含知识检索、语义规划、计划评分、SQL 生成、SQL 校验、执行、结果评分、有限重试和答案生成。
- DeepSeek `deepseek-v4-flash` 通过 OpenAI 兼容接口参与语义规划和答案表达，思考模式开启；不可绕过知识口径和确定性校验。
- 未配置模型密钥时，`auto` 模式安全回退到规则规划和确定性答案生成。

### 前端

- React 19 + vinext 控制台，默认运行于 `http://127.0.0.1:3000`。
- 展示最终答案、综合可信度、知识/计划/SQL/结果四项分数。
- 可信度证据链可查看每一步的实际产出、检查项、权重、得分与失败原因。
- 展示执行路径、生成 SQL、逐轮重试记录和数据环境标识。
- SQLite 模式明确标记为“演示数据”，避免被误认为真实业务数据。

### 当前演示数据

- 知识定义：`data/mock_knowledge.json`。
- 查询数据：`tools/trino_client.py` 中初始化的内存 SQLite 数据。
- Mock 数据只用于验证流程与交互，不能代表生产指标。
- 已覆盖开户人数、交易金额、地区/日期等示例口径及衍生占比查询。

## 已验证场景

- 查询单一地区的开户人数。
- 查询最近多日的日趋势。
- 同时返回总开户人数和各地区明细。
- 基于基础指标计算各地区占比，而非为特定问法写死答案。
- 不支持的指标返回 `unreliable`。
- SQL 或结果低分时进入有限重试，耗尽后拒绝作为可靠指标输出。
- 每轮记录 SQL、返回行数、SQL 分数、结果分数与问题原因。

## 完成定义

当前 Demo 阶段已经完成。完整项目阶段的完成条件见 [生产化路线图](roadmap.md)，核心标准是接入真实知识库和真实查询引擎，并通过数据新鲜度、历史基线及权威报表对账验证。
