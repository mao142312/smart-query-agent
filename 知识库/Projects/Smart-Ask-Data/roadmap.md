# Smart Ask Data 生产化路线图

- 最后更新：2026-08-16

## P0：真实口径与真实数据

- [ ] 建立正式指标知识库：指标定义、负责人、来源表、字段、公式、强制过滤条件、支持维度、更新时间和版本。
- [ ] 将 Mock 检索替换为向量 + 精确匹配的混合检索，并保留命中依据与知识版本。
- [ ] 接入 Trino 或实际查询引擎，配置目录、Schema、超时、扫描量和返回行数限制。
- [ ] 建立开发、测试、生产环境隔离；前端明确显示当前数据环境。
- [ ] 完成首批黄金问题集及人工核验基准答案。

## P1：结果可靠性闭环

- [ ] 接入表分区/数据集更新时间，真实校验数据新鲜度。
- [ ] 为每个指标在知识库中配置合法范围、单位、精度、空值策略和波动阈值。
- [ ] 建立历史同比/环比异常检测。
- [ ] 与权威报表或结算数据自动对账。
- [ ] 将评分规则、阈值和版本随查询结果一并保存，支持审计回放。

## P1：安全与治理

- [ ] 企业身份认证、租户隔离及行列级权限。
- [ ] 使用 SQL AST 做表、字段、函数、子查询和只读安全校验。
- [ ] 敏感字段脱敏，查询与模型调用日志去敏。
- [ ] API Key 改由密钥管理服务托管；配置文件只用于本地开发且不得提交。

## P2：可观测性与评测

- [ ] 记录请求耗时、模型耗时、查询耗时、重试率、拒答率和分数分布。
- [ ] 建立离线评测：指标识别、维度识别、SQL 正确性、答案数值一致性。
- [ ] 建立线上反馈与错误样本回流机制。
- [ ] 增加知识版本升级、回滚和影响分析能力。

## 上线门槛

只有同时满足以下条件，界面才可移除“演示数据”标识：知识来源真实且有版本、查询引擎连接真实环境、权限生效、结果新鲜度可验证、黄金问题集通过、权威数据对账通过。
