# AI 意图驱动工作流代码审查

## 审查范围

- 意图识别与可检索性校验
- 结构化 Top N 知识检索
- 知识候选校验与 Grounded Planner
- LangGraph 与 ScoredWorkflow 编排
- 澄清回答、配置和 Debug 验证报告

## 审查结论

未发现阻止交付的 Critical 或 Important 问题。

## 已发现并修复

1. Grounded Planner 在只有一个候选时会把模型输出的非法指标静默替换成该候选。已删除该兜底，并增加“候选集合外指标必须拒绝”的回归测试。
2. 新 STOP 分支最初返回通用低可信说明，没有使用意图/知识校验生成的具体澄清问题。已增加澄清回答优先级。
3. 测试 LLM 未区分意图与计划两次结构化调用。已按 `schema_name` 提供完整、独立的测试响应。
4. 意图 JSON Schema 的嵌套对象定义过宽。已补充字段、required 和 `additionalProperties=false`，适配严格结构化输出。

## 重点检查结果

- `START` 已连接 Intent Recognizer，知识检索不再直接接收原始问题。
- 可检索性和知识候选任一失败都会进入回答生成，不可到达 SQL。
- SQL/结果重试循环位于意图和知识节点之后，不重复前置模型调用。
- 模型最终指标必须属于知识候选集合。
- 普通响应不新增意图内部字段；Debug 验证报告提供结构化检索依据。
- 本地知识后端明确是加权词法召回，没有被描述为真实向量检索。
